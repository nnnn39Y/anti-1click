# anti-1click

A Chrome extension that blocks Amazon's “Buy Now” button by replacing it with “今すぐ買わない”. It supports Amazon Japan and the United States.

## Install in Chrome (unpacked)

1. On this page, select **Code → Download ZIP**, then extract the ZIP.
2. In Chrome, open `chrome://extensions/`.
3. Turn on **Developer mode**.
4. Select **Load unpacked** and choose the extracted `anti-1Click` folder (the one containing `manifest.json`).
5. Optionally pin anti-1click from Chrome's Extensions menu.

Click the toolbar icon to open the switch. Turning it off restores the original button. After installing or reloading the extension, refresh any Amazon page that is already open.
